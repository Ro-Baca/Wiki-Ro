# Sony internships
## Physical AI Robotics 【R&D, new business】
https://www.sony.com/ja/SonyInfo/Jobs/sgc-recruit/newgrads/internship/master-doctor-internship/08/

### Job description
You will participate in one of the projects and work in collaboration with the members to be responsible for everything from devising the control algorithm to verifying it in simulation, incorporating it into a real robot and evaluating it.  
In addition, depending on the person in charge, they may present their comprehensive results at conferences both domestically and internationally, and during the demonstration phase, they will visit users in the field and participate in experiments and evaluations.

### Application requirements (degree, etc.)
Those currently studying for a bachelor's/master's/doctoral program in Japan

### Essential Skills
- People with experience in developing robots
- Experience with either motor control, motor planning, or cognitive action planning using machine learning
- High software implementation capabilities (especially Python3 and pytorch)

### Desired skills
- Knowledge of kinematics, dynamics, and mechatronics
- Experience using mechanical simulations
- Experience generating manipulation actions using reinforcement learning and imitation learning
- Development experience on RT-based Linux
- Experience using C++ (11 or higher)
- Experience using ROS
- Experience in international academic societies

### Product and service area
Robotics (stage show robots, uneven ground movement, manipulation, actuators, sensors, haptic devices, etc.)

### Development Environment
Linux/Windows  
C++  
Python  
Github  
Simulation (Unreal, Mujoco, IssacGym, etc.)


## User Model and Recommendation System Research and Development/Prototype Development 【R&D Engineer】
https://www.sony.com/ja/SonyInfo/Jobs/sgc-recruit/newgrads/internship/master-doctor-internship/02/

### Job description
You will be assigned to one of the following tasks, depending on your area of expertise.

(1) User model and recommendation system research and development
- Research and algorithm development of user models and recommendation systems
- Exploratory analysis, model development, and algorithm improvement using real data
- Development of verification/simulation environments, data maintenance

(2) Protopripe development
- Development of prototype apps (mainly web applications) that combine the above technologies with AI agents, etc
- UI/UX research and design in proto apps
- Research and verification of Human-AI interaction


### Application requirements (degree, etc.)
Those currently studying at a Japanese undergraduate or third/fourth year or graduate master's/doctoral program

### Essential Skills
(0) Common
- Basic Python programming skills (coding agent available)
- Basic English proficiency (enough to read English documents without any problems)

(1) User model and recommendation system research and development
- Basic knowledge of statistical machine learning and statistical analysis methods
- Knowledge and experience in recommendation technology

(2) Protopripe development
- Experience with front-end development of web applications (React, Next.js, Vue.js, etc.)
- Basic knowledge of UI/UX
- Basic knowledge about AI agents

### Desired skills
- English proficiency (enough to be able to discuss in English)
- Basic knowledge of computer science
- Basic knowledge of deep learning and mathematical statistics
- Interests and knowledge about causal inference/anti-real virtual machine learning
- Experience applying machine learning to business data (tabular data, etc.) (including participation in data analysis competitions such as Kaggle)
- Basic knowledge of SQL, web application frameworks, etc
- Marketing knowledge and experience
- Experience in building and operating cloud and data analysis environments

### Development Environment
Linux/Windows/Mac  
Python (scikit-learn, Pytorch etc.)  
Github  
AWS, Docker
